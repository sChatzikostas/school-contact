# Changelog

## 1.1.0 - 2026-11-28

### Administration

- Refined the administration interface, staff search, filters, sorting, and workflow-context preservation.
- Improved staff-editor and settings validation, advisory duplicate warnings, and unsaved-change protection.
- Added configuration readiness, publication guidance, and more consistent administration feedback.
- Added a cached, manual-release availability check in Help & Information for verified stable GitHub installation packages.

### Public form

- Added a responsive public-form layout, native recipient guidance, and accessible validation feedback.
- Added submission-progress feedback, duplicate-activation prevention, success confirmation, and safe recovery from eligible failures.

### Email

- Refined the UTF-8 plain-text email template with school-unit identity, clearer information hierarchy, and reply guidance.

### Documentation

- Updated the in-product Help and bilingual documentation, including harmonized Greek terminology.

## 1.0.0 - Initial stable release

- First stable SchoolContact release.
- Parent communication form with server-side recipient routing.
- School and staff administration, including dual destination addresses.
- Privacy, anti-spam, duplicate-submission, and rate-limit protections.
- Greek administration guide and local Docker development environment.
