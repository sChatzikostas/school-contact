# SchoolContact

![SchoolContact](school-contact/assets/logo-horizontal.svg)

Φέρνουμε τη σχολική μονάδα και την οικογένεια πιο κοντά. [English](README.md)

Αποθετήριο: <https://github.com/sChatzikostas/school-contact>

Τα αρχεία εγκατάστασης των δημοσιευμένων εκδόσεων του SchoolContact διατίθενται από τη [σελίδα GitHub Releases](https://github.com/sChatzikostas/school-contact/releases).

Το SchoolContact είναι ένα αυτοτελές πρόσθετο WordPress για την επικοινωνία
σχολικής μονάδας, οικογενειών και προσωπικού.

## Βασικές λειτουργίες

- Δημόσια, προσαρμόσιμη φόρμα επικοινωνίας με ομαδοποιημένες επιλογές παραληπτών και οδηγία κοινοποίησης.
- Ρυθμίσεις σχολικής μονάδας, προαιρετικό ονοματεπώνυμο διευθυντή ή διευθύντριας και διαχείριση προσωπικού.
- Αναζήτηση, φίλτρα, ταξινόμηση, ενημέρωση για πιθανές διπλές εγγραφές και προστασία από απώλεια μη αποθηκευμένων αλλαγών.
- Ένας παραλήπτης προσωπικού εμφανίζεται μόνο όταν είναι διαθέσιμος και διαθέτει τουλάχιστον μία έγκυρη υπηρεσιακή ή εγκεκριμένη εναλλακτική διεύθυνση email.
- Ασφαλής δρομολόγηση email στον διακομιστή, χωρίς έκθεση διευθύνσεων παραληπτών στη δημόσια σελίδα.
- Email απλού κειμένου UTF-8, με ταυτότητα της σχολικής μονάδας, οδηγία απάντησης και Reply-To του γονέα ή κηδεμόνα.
- Έλεγχοι εγκυρότητας στον διακομιστή και, με JavaScript, άμεση ανατροφοδότηση, ένδειξη προόδου υποβολής και διατήρηση στοιχείων σε ορισμένες περιπτώσεις αποτυχίας.

## Εγκατάσταση

Απαιτούνται πρόσβαση διαχειριστή και λειτουργικό WordPress. Πριν την
εγκατάσταση προτείνεται αντίγραφο ασφαλείας.

1. Κατεβάστε το ZIP του πρόσθετου.
2. Επιλέξτε Πρόσθετα - Προσθήκη νέου - Μεταφόρτωση προσθέτου.
3. Επιλέξτε το ZIP, εγκαταστήστε το και ενεργοποιήστε το SchoolContact.

Έχει δοκιμαστεί με WordPress 6.8.3 και PHP 8.3.

## Έλεγχος διαθέσιμης έκδοσης

Όταν εξουσιοδοτημένος διαχειριστής ανοίγει τη **Βοήθεια & πληροφορίες**, το
SchoolContact μπορεί να ελέγχει στο GitHub αν υπάρχει νεότερη σταθερή έκδοση με
ανεβασμένο αρχείο εγκατάστασης. Ένα επαληθευμένο αποτέλεσμα διατηρείται για 24
ώρες και ένας μη διαθέσιμος έλεγχος για μία ώρα. Η εγκατάσταση παραμένει
χειροκίνητη από τη [σελίδα GitHub Releases](https://github.com/sChatzikostas/school-contact/releases).

Το αίτημα χρησιμοποιεί τη δικτυακή διεύθυνση IP του διακομιστή και γενικά
μεταδεδομένα HTTP. Δεν μεταδίδονται σκόπιμα στοιχεία σχολικής μονάδας,
προσωπικού, γονέων, ιστοτόπου ή επικοινωνίας. Περιορισμοί δικτύου ή η
διαθεσιμότητα του GitHub API μπορεί να εμποδίσουν τον έλεγχο χωρίς να επηρεάζουν
τις βασικές λειτουργίες του πρόσθετου.

## Ρύθμιση και χρήση

Από το μενού **Επικοινωνία με το σχολείο**, στις **Γενικές ρυθμίσεις**
συμπληρώστε την ονομασία της σχολικής μονάδας και τη διεύθυνση email της. Το
ονοματεπώνυμο διευθυντή ή διευθύντριας είναι προαιρετικό. Στην καρτέλα
**Προσωπικό** προσθέστε διαθέσιμους παραλήπτες με τουλάχιστον μία έγκυρη
διεύθυνση email.

Δημιουργήστε μια σελίδα WordPress και εισαγάγετε:

```
[school_communication]
```

Μετά τη δημοσίευση, πραγματοποιήστε μια ελεγχόμενη δοκιμαστική αποστολή και
επιβεβαιώστε τη λήψη μέσω του ρυθμισμένου συστήματος email.

## Ενημέρωση

Πριν από την ενημέρωση, δημιουργήστε αντίγραφο ασφαλείας και χρησιμοποιήστε
ένα δημοσιευμένο ZIP εγκατάστασης με την κανονική διαδικασία ενημέρωσης ή
αντικατάστασης προσθέτου του WordPress. Έπειτα, επιβεβαιώστε τις ρυθμίσεις και
πραγματοποιήστε μια ελεγχόμενη δοκιμαστική αποστολή μέσω του ρυθμισμένου
συστήματος email.

## Αποστολή email

Τα άμεσα μηνύματα προς τη διεύθυνση της σχολικής μονάδας αποστέλλονται μόνο
εκεί. Τα μηνύματα προς προσωπικό αποστέλλονται σε κάθε έγκυρη καταχωρισμένη
διεύθυνση: υπηρεσιακό email, εγκεκριμένο εναλλακτικό email ή και στα δύο όταν
υπάρχουν και τα δύο. Η διεύθυνση της σχολικής μονάδας λαμβάνει κοινοποίηση
εκτός αν είναι ήδη προορισμός· η ίδια διεύθυνση λαμβάνει το μήνυμα μόνο μία
φορά, ανεξάρτητα από πεζά ή κεφαλαία.
Οι παραλήπτες μπορεί να βλέπουν ο ένας τον άλλον στις κεφαλίδες email. Δεν
χρησιμοποιείται BCC, αυτόματη επανάληψη ή αυτόματη επιβεβαίωση προς γονέα.
Η διεύθυνση του γονέα ή κηδεμόνα ορίζεται ως Reply-To για άμεση απάντηση.

## Απόρρητο και ασφάλεια

Το πρόσθετο δεν αποθηκεύει περιεχόμενα μηνυμάτων ή στοιχεία επικοινωνίας
γονέων. Τα μηνύματα μπορεί να παραμένουν στα γραμματοκιβώτια των παραληπτών
σύμφωνα με τις πολιτικές των συστημάτων email τους. Οι διευθύνσεις email του
προσωπικού δεν εμφανίζονται στη δημόσια φόρμα. Οι εναλλακτικές διευθύνσεις
χρησιμοποιούνται μόνο με έγκριση της σχολικής μονάδας, η οποία οφείλει να
παρέχει κατάλληλη ενημέρωση απορρήτου.

Η φόρμα εφαρμόζει ελέγχους εισόδου στον διακομιστή, nonce του WordPress,
honeypot, ελάχιστο χρόνο συμπλήρωσης με υπογεγραμμένο token, μία χρήση ανά
υποβολή και περιορισμούς προσπαθειών. Οι περιορισμοί είναι τρεις προσπάθειες
ανά πέντε λεπτά και δέκα ανά ώρα, με ψευδωνυμοποιημένα αναγνωριστικά αντί για
ακατέργαστες διευθύνσεις IP. Οι μετρητές αυτοί δεν είναι ατομικοί σε
ταυτόχρονες αιτήσεις και η προστασία δεν αποτελεί απόλυτη εγγύηση κατά της
κατάχρησης.

Με JavaScript προστίθενται άμεση ανατροφοδότηση εγκυρότητας, προειδοποιήσεις
διπλότυπων, προστασία μη αποθηκευμένων αλλαγών και ένδειξη προόδου. Χωρίς
JavaScript παραμένουν διαθέσιμες η εγγενής υποβολή και η επικύρωση διακομιστή,
αλλά ορισμένες απορριφθείσες υποβολές δεν διατηρούν τιμές. Οι ληγμένες φόρμες
και οι υποβολές που απορρίπτονται για λόγους ασφαλείας μπορεί να χρειάζονται
νέα συμπλήρωση. Η επιτυχής υποβολή
σημαίνει ότι το WordPress αποδέχθηκε το μήνυμα για τον ρυθμισμένο μηχανισμό
email· δεν εγγυάται την τελική παράδοση.

Μην χρησιμοποιείτε full-page cache σε σελίδες με τη φόρμα χωρίς μηχανισμό
συμβατό με δυναμικά nonces και υπογεγραμμένα tokens. Τα headers απόκρισης
περιορίζουν τον κίνδυνο caching σε αποκρίσεις ανάκτησης, αλλά δεν ελέγχουν
τρίτα συστήματα cache που τα αγνοούν.

## Γνωστοί περιορισμοί

- Η επιτυχής υποβολή επιβεβαιώνει ότι το WordPress αποδέχθηκε το μήνυμα για τον ρυθμισμένο μηχανισμό email, όχι την τελική παράδοση.
- Οι περιορισμοί προσπαθειών που βασίζονται σε transients δεν είναι ατομικοί σε ταυτόχρονες αιτήσεις.
- Οι έλεγχοι θεμάτων και προσβασιμότητας είναι αντιπροσωπευτικοί και δεν εγγυώνται καθολική συμβατότητα ή πλήρη συμμόρφωση WCAG.

## Τοπική ανάπτυξη

Το `compose.yaml` εκκινεί WordPress, MariaDB και Mailpit. Το SchoolContact
βρίσκεται στον τοπικό φάκελο `school-contact/` και προσαρτάται στο WordPress.

```powershell
Copy-Item .env.example .env
docker compose up -d
```

WordPress: <http://localhost:8086> · Mailpit: <http://localhost:8026>
